Projet Data Mining

Évaluation du risque de décrochage

Cette plateforme permet de préparer les données des étudiants afin d'identifier les profils nécessitant un accompagnement prioritaire à la fin du premier semestre.

Mode d'utilisation

Objectif :
Préparer les informations des étudiants pour une classification par le modèle de prédiction.

Capacité annuelle : 200 places de tutorat.

Importer les données des étudiants

Sélectionnez un fichier CSV contenant les 31 variables attendues par le modèle.
Le fichier doit utiliser les noms exacts des colonnes.

Important : Le fichier doit contenir les variables disponibles à la fin du premier semestre. Les colonnes Target et Dropout_Binary ne doivent pas être fournies comme variables d'entrée. Les colonnes supplémentaires éventuelles sont ignorées par l'API CSV.
